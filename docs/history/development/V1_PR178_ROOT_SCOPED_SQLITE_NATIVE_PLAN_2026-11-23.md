## New integration

- `internal/install/network_peer_scoped_root_transition.go`: `NativePeerScopedRootTransitionFromEvidence(proof state.ScopedPeerOriginalProof, network *api.Network, obs NativePeerScopedRootEvidence)` combines **the already independently authenticated/read-only v2 SQLite original proof** with a complete independent SDK-observed native Project/bridge/instance/ACL inventory. In this function the observed structures are input data, **not a trusted capture mechanism**. A future Root-only collector MUST obtain them from the real trusted Incus socket, protected SQLite and live kernel under original/global resource locks; MCP must not be able to supply or override them.
- Derives every per-Box native UUID, name, MAC, canonical dual-stack lease, incarnation and deterministic per-Box ACL from the complete SQLite scope. Validates exactly all names/observed instances/root default-Project ACL UsedBy, native ACL ETag present, static anti-spoof NIC, exact bridge ownership, and refuses unknown/foreign instance/bridge consumers via the previously tested `NativePeerGuardValidateScopedInventory`. No silent partial inventory or unrelated C/D exclusion.
- `nativePeerRootExactV2Diff` independently verifies that before/after allowlists differ by **exactly one directed pair equal to the authenticated source→target**, including both original incarnations. It checks before/after DROP tombstones (fresh grant=unchanged; revoke=exact DROP added; regrant=prior exact DROP removed), refuses any C/D or inverse B→A change, duplicate peer rows, or an UNKNOWN recovery-only original.
- Compiles both root guard `NativePeerGuardFromSnapshot` pre/post proposals and enforces existing `nativePeerGuardValidateOneDirectionDelta` (one four-rule dual-stack bridge change, all terminal denies unchanged). Independently compiles every Box's ACL before/after from `NativePeerScopedACLFromPolicySnapshot`, not just affected A/B. **All unrelated Box ACLs must be deep-equal pre/post**, otherwise no plan is returned.
- Returns only immutable-style **policy proposals** for source and target ACL and before/after guard, the count of verified unchanged sibling ACLs, and a read-only per-UUID snapshot of each native Box's exact original `boot.autostart` value, including explicit `false`. No SDK ACL PUT, nft batch, conntrack purge, instance stop/start, boot config mutation, root service, systemd or socket permission exists in the new function.
- The function deliberately does **NOT** compare actual observed *ACL rule content* or active *kernel nftables rules* against the expected preimage; that must be part of a separate Root native/kernel read-only collector immediately before any journaled effect. A synthetic `ScopedPeerOriginalProof` constructed by untrusted code is NEVER sufficient authorization to write, even if this function returns successfully.
