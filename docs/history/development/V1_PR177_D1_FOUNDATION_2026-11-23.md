## 1. Implementation and contracts

- cmd/boxweave/main.go routes doctor before state.Open; missing paths no longer initialize DBs. Existing status/serve/other CLI and existing MCP schema remain unchanged. Legacy status still uses writable Open (do not recommend status as strict Doctor or use it for recovery planning). Two historical native CI scripts explicitly initialize disposable test fixtures through existing status before Doctor; do not do this to a missing production DB.
- internal/state/diagnostic_snapshot.go is a new **standalone-process-only** observation API. Never use it inside a daemon or process with live source SQLite handles: closing any fd for an inode can release same-process POSIX SQLite locks. Existing live daemon can reuse its own read transaction instead. No source SQLite connection, mode=ro initialization, checkpoint, serve lock, DDL, write or source WAL/SHM creation. Source directory and DB/WAL/SHM identity, mode, owner, links, device and local filesystem checked. Openat2 rejects ancestor symlinks, file opens are O_NOFOLLOW/O_NOATIME; descriptors pinned, paths and source identity rechecked. Unknown filesystem/OFD support, owner mismatch, alias, unstable state, hot rollback journal or missing active WAL proof refuse.
- SQLite is the pinned go-sqlite3 v1.14.52 default local Unix VFS. A nonblocking exclusive OFD lock on standard DB lock range proves a cold/stationary capture; existing DB opened RW for the lock ONLY, no source writes. Live path uses a shared OFD DB lock and shared WAL writer/checkpoint/recovery bytes (120..122) plus observed active DMS holder (128), rechecked. These conflict with SQLite POSIX locks. Copy DB and WAL only while these cooperative locks exclude write/checkpoint/recovery; private SHM rebuilt by SQLite. Locks released before schema validation/queries. Source sizes max 32 MiB combined, copy budget 2 seconds, DB source budget 5 seconds. No wait for a conflicting write lock; report BUSY/UNVERIFIED. Short compatible capture locks can transiently delay other writes; do not claim zero scheduler contention. No support for arbitrary non-cooperating writers, alternate VFS, hostile same-owner ABA, NFS or oversized DB; fail closed where detected. Revisit lock ABI if SQLite dependency changes. Main-only immutable is never the live strategy.
- Temporary capture in fixed private 0700 directory under sticky tmpfs /dev/shm, files 0600, normal success/error cleanup. A killed process may leave private volatile bytes until local cleanup/reboot; never export or log snapshot path/data, no arbitrary TMPDIR or disk fallback. Context-bounded query-only SQLite validates exact tables/indexes/trigger-view exclusion/quick_check via shared existing validator. Snapshot is NOT IsNetworkAuditReadOnly Root proof; no raw Store returned; exposes Schema, ProjectCapacity and scoped diagnostic summary only. Empty scoped scope allowed by diagnostic-only existing internal allowEmpty reader; mutation-grade public reader unchanged. Observations are snapshot epochs, never live dispatch authority. No claim that captured readable state proves missing external history or hostile filesystem integrity. Access-time changes from ordinary metadata/native observation may occur; no source DB byte/sidecar effects or intentional service/native mutations.
- internal/install/diagnostic_observe.go observes fixed install identity: private service-owned manifest and state directory, root-owned binary/unit digest, actual systemd PID/exe/UID/argv scope, scoped journal metadata and Root-only initial+quarantine proof, scoped static artifacts and effective dependencies. Redacted typed states; no raw argv, secrets, journal or arbitrary native inventory. Separate architecture from exact current static unit contract and current service/guard/helper state. No version-only inference. Healthy legacy requires absence of scoped artifacts/journal/effective dependencies; scoped mode requires exact proof and runtime plus observed guard dependencies. Missing or mismatched evidence is UNVERIFIED/CONFLICT; nonroot scoped actor cannot prove Root journal and gets explicit candidate/ROOT_AUTHORITY_REQUIRED. Stopped daemon cannot prove live argv. No root-only helper invocation for restricted actor.
- Root CLI uses a private, fixed nonroot Native-only worker via kernel Credential UID/GID and restricted Incus group, sanitized environment, same invoking executable, exact installed scope; does not call privileged Native.Reader or legacy install.Status after drop. Child has no write entry point or new permission, no arbitrary paths. Native preflight only attempted when observed Incus service active; no intentionally activating/stopping service. Systemd/other sources are non-atomic and can race; recheck at future effect boundary.
- internal/diagnostic/report.go version 1 report: source state/reason/epoch, mode/candidate/evidence, scoped summary if proven, stable canonical SHA issue ID (scope/domain/code/resource), non-atomic coverage, repairability NOT_EVALUATED. Distinguish stable ID from D3 review digest and D4 idempotency key. Compatibility schema_version/native/ready and mcp_ready fields retained: mcp_ready is schema-only, ready is basic preflight, diagnostic.coverage PARTIAL_D1_FOUNDATION and mcp NOT_CHECKED. Never interpret it as full health. Optional old address retirement/capacity observations omitted from Doctor until D2 qualified implementation; status and MCP unchanged. D1 no recover plan/apply, no Root dispatch via report.
