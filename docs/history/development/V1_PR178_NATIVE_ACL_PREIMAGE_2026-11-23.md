## New scoped evidence and hard boundaries

- `NativePeerScopedRootTransition` now returns `ExpectedBeforeByUUID` and `ExpectedAfterByUUID` maps for **EVERY** claimed Box, not just A/B. All proposals originate from the same global v2 original and full root-native owner inventory; C/D before/after ACLs were already required deep-equal by the planner.
- `internal/install/network_peer_scoped_acl_preimage.go`: `NativePeerScopedVerifyObservedACLPreimage(plan, observed)` is a **pure READ-ONLY** comparison of every tenant's independently observed `api.NetworkACL.NetworkACLPut` and previously compiled expected ACL before-image, including **full ingress/egress rule objects**, description, config map, per-Box UUID, ACL name, native root Project, exclusive exact tenant `UsedBy`, nonempty ETag and explicit `boot.autostart`. Independently checks complete tenant instance-name list and bridge UsedBy whitelist; missing/foreign/sibling input fails closed. No ACL PUT or root effect.
- Incus ACL rule array ordering is *order independent*. Every full rule is canonical JSON serialized, deduplicated and sorted before exact comparison. Foreign extra `accept`, deleted `drop`, changed action/source/destination/description/state, duplicated rule, changed config or foreign ACL UsedBy are refused. A SHA-256 of canonical sorted all-ACL evidence includes each ETag, UsedBy, explicit boot value and all complete rules. Changing a native ETag changes the digest even if policy content remains identical, so a future writer **cannot reuse an old CAS preimage**.
- This witness is **not a trusted root provenance** merely because a pure function returns a digest: a privileged collector must recapture and verify real SDK state and actual kernel nft JSON/sysfs/foreign NICs under all Root locks immediately before any write, and verify after the write. No caller, MCP or guest-supplied structure may authorize an effect, and the current Root helper/old stop-all flow remains unchanged.
- **Important test-discovered aliasing hazard**: initial test fixtures assigned `NetworkACLPut` by *shallow* copy from the same expected plan, causing an attempted mutation of actual `Egress[0].Action` to also mutate the expected underlying slice. This falsely passed one deliberately injected drift. The fixture was corrected to independently clone `Config`, `Ingress`, `Egress` and description with `maps.Clone` + `slices.Clone`. The fault now correctly fails. Future root collector must use independently captured isolated snapshots and never compare two aliased mutable SDK structures.
- Neither this nor previous v2 Root plan has read actual running Box C/D network ACL rules from a dedicated production tenant; these tests use isolated SDK fixtures. The separate earlier Incus 7.6 native guard/ACL experiments are the only current real kernel evidence and do not constitute v2 deployed end-to-end acceptance.
