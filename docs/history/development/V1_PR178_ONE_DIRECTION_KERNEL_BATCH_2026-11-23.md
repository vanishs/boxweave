## New code and hard boundaries

- `internal/install/network_peer_guard_transition.go`: `nativePeerGuardValidateOneDirectionDelta(before,after)` rejects any change beyond **exactly one four-rule dual-stack directed Peer group**, while the four full-bridge IPv4/IPv6 and link-local deny/ND rules and every unaffected C/D group remain byte-identical. Rejects a different guard table, unchanged policy, forged digest, multiple grants at once, simultaneous unrelated revoke, changes to baseline deny, unbounded nft script, `flush ruleset`, foreign subcommands and duplicate groups. This is only a defense in depth: ROOT MUST bind the exact pair to a protected authenticated original, not accept caller-selected replacement text.
- Internal `nativePeerGuardReplaceOnce(ctx,before,after,witness,batch)`: rejects any insecure delta or unverified **preimage** before writing. Executes at most ONE supplied batch callback; once invoked, any error is classified **attempted and UNKNOWN**, not an automatic replay. Success requires a fresh exact **postimage** witness; all other outcomes return `KernelVerified=false`. The returned `nativePeerGuardReplaceOutcome` is intentionally EPHEMERAL and **NEVER** a durable original or complete Peer receipt.
- Internal root-only `nativePeerGuardFixedNftBatch` invokes fixed `/usr/sbin/nft -f -` with stdin script, restricted environment, **no shell and no CLI/MCP path**. Its permission is deliberately NOT reachable from current installed Root Helper. It is unsafe to call before a separate fsynced one-original journal, live root Incus/SQLite/sysfs/nft preflight, host-wide foreign route audit and exact operation lock ownership are implemented.
- `internal/install/network_peer_guard_transition_test.go`: positive single A→B grant/revoke with C/D unchanged, and negative combinations for no-op, multi-peer mutation, foreign Project/table, altered terminal DROP, forged SHA and injection-like nft scripts. Faults inject missing before witness, cancelled original, kernel write that **applied but lost ACK**, and kernel post-readback failure. For ambiguous native effects, all cases prove `Attempted=true` but `KernelVerified=false` and **one attempt only**.
