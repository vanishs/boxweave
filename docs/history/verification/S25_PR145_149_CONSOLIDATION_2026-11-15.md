## Sequence after consolidation

1. First establish the **smallest non-destructive test** that isolates OAuth same-grant refresh × key K with exact original native and guest side-effect count, compared with a second unrelated grant; keep manual tokens and private read authorization correct.
2. Then test Create and Delete SQLite cut boundaries in **fresh dedicated disposable** ledgers/services with original receipts, SIGKILL before/after commit, and negative foreign/UNKNOWN lock controls. Do not assume another SQLite atomic patch before exact failure is reproduced.
3. Separately retain BH-019 **BLOCKED** for independently delegated enforced policy namespace/Policy Admin, cgroup-device BPF attach+deny, durable UID/GID leases, sibling/cross-Project IPv4/IPv6 packet security and real quotas. The 2026-11-15 native AppArmor parser243 and nested BPF EPERM confirm platform-level constraints in the tested kernel, not an approved workaround.
4. For **every eventual fix**: independent installer + real HTTP MCP + original native postread + separate Verifier, same final SHA quality/S1/dualarch/native Actions, truthfully updated BH acceptance. Keep PR #146 Draft while gates are missing.
