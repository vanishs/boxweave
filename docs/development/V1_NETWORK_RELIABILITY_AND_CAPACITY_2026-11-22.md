Status: DRAFT / implementation started. Owner decision, 2026-11-22 PT: no legacy Box migration is required before the first stable release. Normal owned-Box faults must be diagnosable and, where independent proof permits, recoverable by the authorized MCP actor. Host-local intervention is reserved for genuine service/daemon/host trust failures, not routine Box administration. Do not remove fail-closed authorization or claim recovery when native state cannot be established.

## Work packages and acceptance

### N1 - Unified live capacity
Target 1024 owned Boxes per Project, including stopped instances, plus unresolved original Creates that do not already correspond to a counted owned incarnation. Uncertain released Create claims cannot count as verified absence. Exact replay must precede the capacity guard. Admission must be atomic under concurrent callers; never delete or start another effect to create room. Return a typed pre-admission capacity refusal and report same-Project ledger capacity through `host_status` with explicit scope (not a promise of address/storage availability).
Unify the live cap across state, allocator, native isolation, root inventory and host route auditing. Inventory mismatch still fails closed. Test 1023/1024/1025, pending and concurrent Creates, replay, verified deletion, UNKNOWN and separate Project scope. Verify wall-clock and memory costs at scale, PRS request/journal/operation budgets and complete root/kernel proof; do not treat synthetic SQL fixtures as native scale acceptance.

### N2 - Native address capacity and history
Fresh native preparation/bootstrap must select an independently verified nonoverlapping IPv4 subnet of at least /21 (2048 total addresses, minus network/broadcast/gateway and other reservations) or enforce the smaller actual usable capacity before native dispatch; account for IPv6, DHCP/static reservations, retained historical claims, and other host resources. Existing networks are never silently resized. Address exhaustion must be distinguished from live Box limit. Audit actual free slots and concurrency; verify the installed default and provide clear typed refusals.
Remove the 256-deletion lifetime audit ceiling via indexed, complete, bounded-resource historical verification, without truncating proof. Design safe retirement/reuse with original tombstone, no pending effects or stale peer grants, full current native and kernel readback, transactional uniqueness and race protection. Retain durable evidence and never infer safe reuse from RELEASED alone. Test churn beyond 256 and full pool recycling, same-IP different-UUID access denial, failures, restart and overlapping foreign networks. No old-version migration.

### N3 - MCP network diagnosis and recovery
Use existing `host_status`, `box_activity_get` and `operation_recover` first; avoid new tools unless an explicit contract decision requires one. Provide bounded/paged complete scope, actionable owned Box UUID/incarnation and original operation, typed reason for missing pin/fence, mismatch/duplicate, active claim, capacity, native drift, ambiguous proof. No foreign inventory disclosure; do not call NORMAL active dependencies errors.
Map each normal lifecycle failure cut to recoverable original and safe action: Create staged/ACK-lost/terminal-write fault, Delete pending/ACK-lost/tombstone, incomplete verified binding, address conflict, owned native NIC drift, and restoration inconsistency. Distinguish independently proven no effect, verified original terminal poststate, safe exact repair, and genuinely unprovable corruption. Existing inspect/reconcile must first be tested before expanding it. If exact original evidence permits, journal a separate idempotent repair operation, preserve the original and its UNKNOWN protections until independent proof is complete. Never manually seed rows or bypass locks. No arbitrary IP choices, adoption of foreign identity, blind replay, blanket unlock, or widening native privilege. Normal owned-Box recovery must not require an interactive root visit; service or trusted verifier unavailable, irreconcilable ledger/database corruption, out-of-band shared network trust break, or foreign ownership remain explicit Host-level escalations.

Repeat partial-failure and restart cases, retained historical identities, safe no-effect recovery and ACL/IP reuse. Preserve original operation references and evidence. No merge or release until exact-head gates and scoped independent acceptance pass.
