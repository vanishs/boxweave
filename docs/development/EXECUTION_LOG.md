### 2026-11-13 — RFC 9700 refresh-token reuse security gap closed at a8dd90

- On extra security review after earlier OAuth source/Box Actions were green, found that consumed refresh token digests were deleted; public-client OAuth 2.1 / RFC 9700 requires retained grant linkage and replay-triggered revocation of the successor.
