Enable **daemon-global** authorization.client.tls-restricted=scriptlet via safely reviewed policy merge preserving existing restricted clients' Project rights; test old clients' *allowed and denied* paths **before/after**, including rollback. If compatibility cannot be proven, mark this feature BLOCKED without granting full Incus administrator to MCP. Never overwrite an unrecognized existing Scriptlet.
2. **Before first Box start:** configure owned NIC with shared ACL, default **ingress reject / egress allow**, native source IP/MAC anti-spoof for supported IPv4/IPv6, verified assignment and stable UUID→NIC/IP mapping. Reject start/peer grant if no safe IPv6 enforcement or ownership evidence. Do not attach ACL to foreign NICs or automatically reconfigure host bridge.
3. **Private peer:** implement box_peer_set(A,B,true/false) from **owned source+target Box UUID** and current IP(s); generate whole allowlist from durable directional grants (**all ports**, no arbitrary CIDR/port DSL), use official SDK GetNetworkACL/ETag/UpdateNetworkACL, validate exact native ACL used_by and readback. B→A new flows remain denied unless independently allowed. Track desired/DB/attached/kernel-witness separately; native Bridge reapplies ACL to NICs **one by one**, not atomically. On partial apply, recycled IP, missing native state or ETag conflict, no success claim and prevent unsafe new grants.
4. **Native instance-owned TCP/UDP proxy devices:** port_forward_create/list/delete operate on **verified owned Box + host bind/port + target guest port**, ordinary local default loopback, explicit authorized LAN/public bind, conflict/unsupported protocol denied. Host-loopback proxy remains independent of private Box peer grants. Never expose arbitrary foreign target IP, claim loopback is LAN-accessible, or silently create a separate network forward service.
5. **Integrate Box deletion across dependent claims (S2 closure):** preflight/lock exact Box UUID plus owned forwards and peer grants; document normal cleanup scope; remove and verify owned proxy devices and peer rules **before** native Box delete; commit tombstone only after independent exact readback. Fault-inject forward removal succeeded but Box deletion fails, lost reply after successful native delete, partial SQLite commit/compensation failure, and concurrently racing peer/forward changes. Surface original step/evidence through operation_get, box_get and port_forward_list; no foreign cleanup, no blind re-dispatch. **Reaccept S2 box_delete A-043–046 here**.
6. **Nested L1/L2 parity:** First reaccept S2.5's actual unprivileged L1 selected storage/Exec-spool quota and inner bridge/NAT (or close its documented blocker safely), then install exact v1 build inside a supported nested Box, using new local credentials at that layer only. Guest-local client connects to inner loopback MCP via allowed parent guest Exec; never pass parent Incus sockets or root credentials to child. Same 20 Tool schemas, Box agent loop and native owned-resource semantics where supported; nesting must not silently disable anti-spoof. Parent↔child routing uses ordinary explicitly configured per-layer native forwards, not an orchestration feature.
7. **Real independent network witnesses:** A↔B same bridge IPv4 and enabled IPv6 with reply/reverse tests, revoke and new established connection evidence; host native TCP+UDP, alternate bind/port collision, real service daemon surviving original Exec; physical LAN machine to L0 LAN bind, and L0→L1 through separate forwards where authorized. **The separate physical-LAN witness is S5-required, S4 optional**; label loopback-only evidence as partial, not public LAN PASS.
