## Product boundary and practical engineering choices

- Keep the selected **one installer-precreated, BoxWeave-exclusive Incus bridge ACL**, attached to each verified owned Box effective NIC, with NIC-local default ingress reject and IPv4, IPv6 and MAC source anti-spoof enabled. Existing S1 ACL egress private/reserved CIDR rejects and bridge gateway exception are immutable baseline; calculate only BoxWeave-owned ingress grants and never erase/rewrite unrelated egress entries. The native *default Profile* retains egress default reject; an approved owned Box may have its separate per-Box `internet=true` egress allow. The B1 throwaway experimental Profile set allow for packet tests, **not** a proposal to change this S1 invariant.
- Grant identity is `Project + source UUID/incarnation + target UUID/incarnation`, **not** a user-provided name, IPv4/IPv6, MAC, NIC name or Project alone. Native `volatile.uuid`, effective NIC, ACL name/Project, anti-spoof flags and currently exclusive IP/MAC binding are all checked on every peer/forward use. A foreign ACL `used_by` reference, unexpected writable rule or lease change blocks writes until safely reviewed. Verify full Profile reference **and** every direct/expanded NIC, not merely `len(used_by)`.
- Use the official Incus SDK without a new proxy daemon, host firewall API, Incus admin MCP Tool, arbitrary ACL DSL, new authorization backend or general API wrapper. Expose only four final tools, bringing 16 → 20 later, not in B1. Restricted non-root instance SDK connection and dedicated **server-pinned exact-ACL GET/PUT-only TLS+Scriptlet client** are distinct credential paths.

## Four exact public tool contracts (B3/B4)

All inputs are strict typed JSON; unknown fields rejected. Mutation replies reuse the existing durable `state.Receipt`/original `operation_id`, `tracking_id`, `state`, `native_operation_id` **only where actually returned**, `next_action` and `work_ref/agent_ref`. Return an immutable assigned `forward_id` in the forwarding receipt/operation metadata after admission so a same-key replay returns the same identity, not a new device. Every mutation requires an admin principal and 16–128-character reusable `idempotency_key`; optional existing work/agent labels are not authorization. Viewer may use the one read tool and already permitted Box metadata; no viewer mutations. Repeated same actor+key+same canonical intent returns the original, while changed intent conflicts. Stable OAuth grant actor survives access-token refresh.

| Tool | Input / output contract | Explicit refusal |
| --- | --- | --- |
| `box_peer_set` | `{source_box_id:UUID,target_box_id:UUID,allow:boolean,idempotency_key:string,work_ref?,agent_ref?}`. Original async receipt; later `box_get` exposes verified directional current grant/observed status. No arbitrary CIDR, protocols, guest IP or ACL body. | Unknown/foreign UUID, self-pair, unsupported topology/IPv6, stale native Box, unsafe binding, active lock, foreign shared ACL use, unresolved kernel reload or UNKNOWN. |
| `port_forward_create` | `{box_id:UUID,protocol:"tcp"\|"udp",guest_port:int,host_port:int,host_bind?:string,idempotency_key:string,work_ref?,agent_ref?,exposure_ack?:boolean}`. Ports 1–65535; `host_bind` omitted = exact `127.0.0.1` loopback. An exact approved LAN host IP is a separate explicit admin exposure acknowledged by `exposure_ack=true`; wildcard and unverified public bind can be UNSUPPORTED. Persist and return stable `forward_id`/original receipt, then actual device/readback and actual service probe status separately. | Unknown guest address or Box UUID, foreign native device, duplicate bind/protocol/port on host, non-TCP/UDP, unauthorized host bind, running unknown operation, unsupported native Proxy. |
| `port_forward_list` | `{box_id?:UUID,limit?:int,after?:opaque_cursor}` → `{tracking_id,forwards:[{forward_id,box_id,protocol,host_bind,host_port,guest_port,state,observed_native_device,observed_listener?,error_class?}],next_cursor?}`. Deterministic bounded keyset, no foreign/orphan names. | Foreign Box, unscoped unsafe enumeration, stale native inspection returned as known active. Status distinguishes desired/observed/UNKNOWN. |
| `port_forward_delete` | `{forward_id:string,idempotency_key:string,work_ref?,agent_ref?}` → original durable receipt. Resolve `forward_id` from this controller's owned SQLite claim, check exact Box UUID/incarnation and immutable native proxy device fields; remove only that device, read back device absent and no longer listening (where observable), tombstone claim. | Unknown/foreign forward, device drift/name collision, unresolved actor/Box/network lock, native error/lost ACK (UNKNOWN; no redispatch). |

`exposure_ack` is an explicit capability acknowledgement, not bypass of scope or proof of LAN reachability. `host_bind` address/source validity is checked against host network observations through authorized installer/native APIs; never accept a caller-supplied arbitrary upstream IP. An unreachable Guest service is not equivalent to wrong ownership or a successful TCP application probe. Real LAN/public bind tests remain S4/S5 scoped and may be UNSUPPORTED without host consent.

## Minimal persisted model, locking and transitions (B2 foundation)

**Extend the exact SQLite schema intentionally**: `internal/state/store.go` v2 is fingerprinted, so a changed fresh pilot schema must be versioned/reviewed; do not silently open old L1 RC7 DBs or claim automatic migration. Minimal additions proposed:

1. `network_bindings`: one live record per exact Box UUID+incarnation+Project and effective NIC identity; current independently verified MAC, IPv4, IPv6, bridge/ACL, observed generation/time, anti-spoof proof. These are **observations**, not permanent rights; no lease allocation semantics assumed until proved.
2. `peer_grants`: unique ordered `(project,source_uuid,source_incarnation,target_uuid,target_incarnation)`, desired allow/revoke, current applied IPv4/IPv6 pair/ACL generation, original operation reference and `PENDING|CONFIRMED|UNKNOWN|REVOKED` status. ACL rules regenerated **as a whole** from precisely confirmed eligible grants, preserving S1 egress baseline.
3. `forward_claims`: stable ID and unique active `(host_bind,protocol,host_port)`; exact Box UUID/incarnation, native device name, guest_port, target IP snapshot, desired/observed state, original operation pointer, tombstone. A colliding **foreign** host socket is not ours even if SQLite's local uniqueness passes.
4. `operation_resource_claims`: atomic set of typed keys per admitted operation, acquired in deterministic order **in the same SQLite admission transaction**. Keys include `box:<name>`, shared `acl:<project>/<acl>`, and `listener:<bind>/<protocol>/<port>`; peer claims both endpoint Boxes and ACL, forwards Box+listener, Delete its Box+ACL+all owned dependent listener claims. Existing one `operations.resource_key` remains supported; do not open a TOCTOU window by enumerating dependents before a Box claim. Incomplete/UNKNOWN claims remain latched until independently reviewed.

Do not create an additional general network transaction coordinator. Keep native steps idempotent at the **evidence** level but never blindly redispatch a native mutation on transport loss. A real successful ETag PUT can produce already-updated native ACL while a client gets a timeout.

**Synchronous ACL-specific mutation path is mandatory:** `UpdateNetworkACL` gives only `error` and **no native operation ID**. The S4-A Worker presently treats `nativeID==""` as UNKNOWN; B2 must add a separate explicitly typed journalled synchronous effect with an immutable original intention, sent/possibly-sent bit, durable before-dispatch record, complete exact ACL+ETag+NIC postread and explicit terminal class. Do not misuse the no-effect sentinel or invent a native Operation UUID. The existing async native instance update/delete receipts remain unchanged. On HTTP 412, recompute only after independent fresh ownership/binding/ACL read, with bounded contention policy; on timeout/partial reload/DB ACK uncertainty retain UNKNOWN and block dependent changes.

**Provider atomicity is limited:** ACL ETag guards SQLite-level provider ACL updates, **not** the per-NIC kernel reload fanout. Tagged `BridgeUpdateACLs` iterates running NICs separately and stops on first error. The only safe guarantee currently established is a successful ordinary test flow. B2 must define refusal/hold behavior and independent packet/readback checks. Do not promise all NICs update or that established sessions die immediately. If network state cannot be fenced and converged, disallow grant rather than pretending rollback succeeded.

**IP lease/reuse is an unresolved safety gate:** a source/destination pair keyed only to current dynamic IP can later match a *different* Box legitimately receiving an old lease. Periodic polls alone cannot guarantee no interim exposure. B2 should select a **native-exclusive address reservation/pinning** mechanism verified in an authorized real bridge, or enforce stop/revoke/confirm-denied before lease release/reassignment; retain old address quarantined until policy convergence. If neither is provable, `box_peer_set(allow=true)` is UNSUPPORTED on that topology. Proxy's `connect=...` target IP has the same reuse problem: revoke/remove or rebind before reallocation.

## Installer Scriptlet and lifecycle sequence (B2/B5)

1. **Host-local preflight only:** read and fingerprint old `authorization.client.*`, Scriptlet contents, trusted restricted TLS certificates/Project restrictions, ACL, network, Profile and existing `used_by`. No MCP-facing host admin. Existing S1 `NativePreparePlanReview`/Apply/Rollback gives the scaffolding; extend rather than replacing it. Refuse preexisting unknown ACL or incompatible Scriptlet.
2. Obtain **new, explicit host-specific approval** before modifying `authorization.client.tls-restricted=scriptlet` or Scriptlet itself—even on an experimental host. The product-level previous choice does not authorize changing a concrete shared daemon. Pre-authorized temporary tests in 2026-11-08 are historical evidence only. Without new approval, source/unit/read-only tests allowed; actual host switch marked **BLOCKED**.
3. Install dedicated restricted certificate with private key confinement and server cert pinning. Scriptlet checks authenticated exact credential fingerprint, scoped Project and **GET/PUT of exactly one existing owned ACL**, denies create/delete/rename/foreign resources. Never allow Project-level `can_create_network_acls` (cannot constrain target ACL name). Every other preexisting restricted certificate must maintain its per-Project positive *and negative* permission matrix; a generic allow-unknown fallback is forbidden.
4. Backup old route, policy and inventory; test new route against existing clients; on mismatch rollback **exact old bytes/config**, independently read rights and local root admin recovery. Crash/retry after partial daemon config is a protected operator incident, not a second automatic blind apply.
5. For Box Start, verify owned effective private NIC, observed lease and grants first. For `box_peer_set`: verify both exact UUIDs and address ownership, reserve resources, derive the whole owned ACL ingress set, GET/ETag PUT, independently re-read ACL/used_by/effective NIC and real packets where required. On 412 bounded recompute; on provider uncertainty retain UNKNOWN and hold new grants.
6. For Proxy: reserve Box+listener, validate verified guest IP and exact native device, issue `UpdateInstance` with ETag, persist original native Operation ID when present, read native device/listener and perform actual TCP/UDP service probes; deleting/rotating a guest IP requires reassignment safeguards.
7. For `box_delete`: atomically claim Box + shared ACL + dependent owned listener keys; mark Delete plan and freeze new peer/forward admissions; revoke all owned inbound/outbound pairs, verify ACL and new-flow deny, remove exact instance-owned proxy devices, verify native device/listeners, then stop/delete only the exact owned Box. After **original native Delete final + absence** call existing S4-A `FinalizeVerifiedDelete` to commit tombstone with original successful receipt. Partial proven cleanup is a true partially-effected FAILED operation with remaining claims; ambiguous effect/ACK is UNKNOWN and locked. Never remove foreign device or the shared ACL with unrelated consumers, and never claim atomicity between SQLite and Incus.
