## Three passes, one acceptance gate

1. **Discovery, one bounded batch.** Capture exact original receipts for tests
   already run, identify missing installed authority links, and run ONLY targeted
   experiments whose answers change implementation. Freeze scope and an
   executable failure matrix before product coding. No speculative new features.
2. **One concentrated implementation.** Connect installed S1 network/ACL,
   protected SQLite claims, nonroot controller to strictly scoped root handling,
   approved Scriptlet change and old-client parity, complete IPv4/IPv6/conntrack
   revoke, no-replay/reconcile/lock, and native drift/fail-closed containment.
   After this single coherent vertical integration, repeatedly test/fix in fresh
   disposable L0 and standalone native Incus 7.6. Keep B2 Tool writes unavailable
   until authorization and all native denial gates are real.
3. **Independent acceptance and finish.** One final immutable SHA, full make
   verify, installed CLI/MCP OAuth actor test, dual-stack packets and
   established-flow revoke, third-party/cross-project noninterference, crash/
   lost-ACK/partial-NIC recovery, Scriptlet old-client parity and rollback,
   host-root lock/journal proof, independent verifier and cleanup. If any P0
   fails, keep PARTIAL; no cosmetic percentage or false PASS.

**Time-box rule:** Reuse confirmed test evidence; run no experiment twice without
a new hypothesis. Each new experiment must end in a concrete product decision.
Do not reopen unrelated nested AppArmor/BPF research (S5).
