## New code and ownership boundary

- `internal/install/network_peer_scoped_root_sdk_collector.go` now contains the previously missing read-only SDK adapter `nativePeerScopedIncusReader`. It receives an **already privileged exact Root `incus.InstanceServer`**, calls `UseProject("default").GetNetwork` and `GetNetworkACL` for root-created bridge and separate ACLs, and `UseProject(<protected tenant>).GetInstanceNames` and `GetInstance` for every scoped tenant Box. No arbitrary shell, no state mutation, ACL PUT, conntrack or network restart methods are present. **The caller must provide a trusted local Root socket; the interface cannot authenticate the SDK connection by itself.**
- Package-private `nativePeerScopedRootCollectReadOnly(ctx, protectedReadOnlyStore, trustedRootSDK, exactOriginal, tenantProject, bridge)` gets **`state.ReadRootScopedPeerOriginal` internally** from read-only SQLite, rejecting unclaimed/forged/UNKNOWN originals, and gets it **again** after full SDK reads. This is a step beyond accepting caller-created `ScopedPeerOriginalProof`, but not a trust boundary for native effects without locked original+kernel.
- `nativePeerScopedRootReadSnapshot` demands exact root-default bridge identity and **nonempty network ETag**, complete bounded (2–1,024) tenant Instance names exactly equal to every SQLite owner, nonempty per-instance ETags and exact native instance UUID, independent root-default ACL names and nonempty per-ACL ETags. It gathers all ACL objects/tenant profile+Instance `UsedBy` and native NIC/ACL state for the strict existing native policy and preimage verifier.
- `nativePeerScopedRootReadOnlyWithDriver` collects this entire native SDK graph **TWICE**, requiring deep equality of all returned network, tenant names/instances, ACL contents, owner Instance ETags, ACL ETags, network ETag and UsedBy. It then combines exact v2 before/after A/B ACL and nft bridge policy with `NativePeerScopedRootTransitionFromEvidence`, requires every unrelated C/D ACL unchanged and applies `NativePeerScopedVerifyObservedACLPreimage` against all ACTUAL captured full rule sets. Any concurrent staged drift, foreign consumer, missing ACL, unexpected ACCEPT, wrong MAC/IP/UUID, ETag change or incomplete tenant inventory rejects. The returned read-only plan contains one original, preimage SHA, per-Box flags, original network and instance CAS metadata.
- **No Root write authorization**: the SDK snapshot is not an atomic global kernel transaction and can drift *after* the second read. Future production Root must hold original+bridge locks, independently recapture live sysfs/port/nft JSON and the same Incus/SQLite preimage at effect time; use a durable full-operation journal, not just private nft step journal. A successful read-only function must never be mistaken for `COMPLETE_VERIFIED`.
