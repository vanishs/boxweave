# Historical phase execution protocol

S1–S5 and S2.5 phase cards are historical evidence, not a task queue. Do not restart a completed phase or follow old handoff commands.

For an explicitly authorized new multi-stage task, identify its scope and observable acceptance, perform focused work, preserve original receipts and exact evidence, and report unresolved checks. Continue independent work only when it is within that task. Stop when complete or blocked; no automatic phase advancement or mandatory learning cycle.

Current verification: [quality gates](../process/QUALITY_GATES.md), [acceptance](../verification/ACCEPTANCE.md). Historical evidence: [phase archive](../history/development/phases/README.md).
