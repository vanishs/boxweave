# SDK-first second-pass gaps: native call semantics and P0 design constraints

**Date:** 2026-11-07  
**Branch:** `v1`; documentation/design only, **no v1 runtime implemented**, **no native Incus/MCP integration PASS**.  
**Pinned source baselines:** Incus [v7.6.0](https://github.com/lxc/incus/tree/v7.6.0) and official MCP Go SDK [v1.8.0](https://github.com/modelcontextprotocol/go-sdk/tree/v1.8.0). The observed external Box host in [last live probe](../verification/SDK_NATIVE_BOX_PROBE_2026-11-07.md) ran Incus **7.5.1**; it was not a 7.6.0 SDK verification.

## Goal and precedence

Close implementation-relevant omissions in the [first SDK fit report](OFFICIAL_SDK_FIT_2026-11-07.md) and [20-tool mapping](SDK_TOOLS_NATIVE_MAPPING_2026-11-07.md), without expanding the P0 product. Trust official SDK operations as intended; BoxWeave must choose the **correct** SDK modes and document limits. An SDK's correct behavior may nonetheless differ from a BoxWeave business requirement. The [owner-approved product boundary](../decisions/PRODUCT_BOUNDARY.md) prevails until an explicit owner change.

Evidence terms: **SOURCE-CONFIRMED** = exact tagged source/docs; **DESIGN** = chosen v1 mapping, not executable proof; **NATIVE-UNKNOWN** = real daemon/client verification needed; **OWNER-DECISION** = never silently weaken the approved contract.

## Findings

| ID | Priority | Specific upstream evidence | v1 correction / minimal remaining proof |
|---|---|---|---|
| G01 | **P0 — auth** | MCP SDK's **tagged docs** say tool handlers read authenticated `req.Extra.TokenInfo`; `auth.TokenInfoFromContext` is for **HTTP middleware handlers**. Streamable source attaches request-specific `RequestExtra{TokenInfo: ...}`. | In **each typed Tool handler**, require non-nil `req.Extra.TokenInfo`, extract credential ID and role via BoxWeave's own verifier, check actor/role/UUID ownership and then admit action. Avoid using the HTTP context accessor as the tool identity contract or caching identity globally in a shared server. |
| G02 | **P0 — auth** | SDK `RequireBearerToken` verifies each HTTP request; `TokenInfo.UserID` can bind **legacy stateful MCP sessions** to one principal. `ToolAnnotations` are only hints. | Keep stateless transport as preferred. Set a stable non-secret principal/credential identifier in `TokenInfo.UserID`, not the raw bearer token; check **current token revocation on every new HTTP request** and again at worker pre-dispatch for queued work. Verify two different credentials, role changes, revoked requests, and old-protocol clients. No custom MCP session or OAuth implementation. |
| G03 | **P0 — ACL** | On Incus **Bridge**, network-level ACLs cannot isolate same-bridge instances; NIC-attached ACL is needed. **Bridge ACL groups/network selectors are unsupported** (unlike OVN). Bridge ingress `reject` may be rendered as `drop`; baseline service rules run ahead of ACL rules. | A generic “ACL per UUID” cannot be assumed to exist on Bridge. Keep a single tested NIC-attached policy. Any address-based pair rule must bind to verified current guest addresses and native NIC anti-spoof controls; on IP/MAC change, name/UUID reuse or unsupported IPv6, remove/withhold grant and **fail closed**. Prove the requested directional A→B initiation and replies, B→A denial, and rule convergence with actual packets. Never claim an attached ACL name equals isolation. |
| G04 | **P0 — file** | `InstanceFileArgs.WriteMode` is `overwrite`/`append`, without compare-on-write. Server-side regular-file POST uses **`os.O_CREATE|os.O_TRUNC`**, not `O_EXCL`. `DeleteInstanceFile` has no caller-hash precondition; the backend has a different force-delete path. | `CreateInstanceFile` alone **cannot** implement `box_file_apply(create)`'s “fail if exists” condition. Evaluate an official `GetInstanceFileSFTP` client using `OpenFile` with exclusive creation **in an isolated guest**; do not claim SFTP O_EXCL semantics until native-tested. Conditional replace/delete need an actual atomic solution or honest `UNSUPPORTED` (and an owner decision if this blocks the P0 workflow). A pre-read SHA is not atomic CAS. Never expose native recursive deletion or accept symlink/special-file substitutions. |
| G05 | **P0 — Exec** | In Incus SDK `ExecInstance`, `RecordOutput=true` **and** non-nil `InstanceExecArgs.Stdout`/`Stderr` invokes `op.Wait()` internally before returning; source also fetches/deletes recorded output logs. The exec-output download helpers are **unexported** SDK methods and the standard public `GetInstanceLogfile` addresses a distinct log URL. | Do **not** select this combination for a v1 tool that promises immediate durable async receipt. Spike the ordinary SDK Exec websocket-output path, promptly persist native op ID and bounded stdout/stderr in BoxWeave, await completion in its worker. Alternative native recording mode must demonstrate exported, safe output access and disconnect/restart behavior before selection. No manual raw Incus REST endpoint simply to impersonate an SDK capability. |
| G06 | **P1 — project bootstrap** | New Incus Project normally isolates `features.profiles`; its isolated `default` Profile may **lack a root disk**. Project `features.*` changes can become locked after the first instance. Project network access/limits are separate from privilege confinement. | Host-local installer must **preflight and provision** the permitted project/profile root pool, effective NIC/network, `features.*` choices, `restricted.*` settings and capability extensions **before first Box creation**. Never silently switch to a foreign `default` project's profile or mutate the shared Incus daemon to fix a missing profile. Keep restricted `incus`-only service user as **first candidate**, and test its exact ACL/proxy rights rather than assuming Project membership proves them. |
| G07 | **P1 — nesting versus network security** | Incus documents `security.mac_filtering`, `security.ipv4_filtering`, `security.ipv6_filtering` as native anti-spoofing controls, and warns they constrain nested bridged/macvlan use of a *different MAC*. | Prefer native anti-spoofing as part of a tested Bridge NIC topology. For `nesting=true`, verify a separate inner managed bridge with NAT/routing through the owned parent's approved NIC; **do not** broadly disable parent filtering merely to support arbitrary nested L2 bridging. Unsupported nested topology is `UNSUPPORTED`/blocked, not a reason to add a host firewall platform. |
| G08 | **P1 — read-only wait concurrency** | Incus `GetOperationWait(uuid, timeout)` calls `getUnderlyingHTTPTransport()` and **sets `ResponseHeaderTimeout = 0`** on the transport returned from the shared client; it sends a native `/operations/{id}/wait` request. `Operation.WaitContext` may cancel the native operation on a different path. | For read-only `operation_get(wait_ms)`, prefer **bounded normal `GetOperation` polling** as the simplest safe default. Use `GetOperationWait` only once its transport impact, concurrent usage and timeout semantics are independently checked; do not mutate the shared HTTP transport from a separate app wrapper to counteract the SDK. Never use `WaitContext` as observational polling. |
| G09 | **P1 — native feature detection** | `ExecInstance` checks native `container_exec_recording` when recording output and `container_exec_user_group_cwd` for non-default User/Group/Cwd. Network ACL, proxy and SFTP availability must also match running Incus capabilities; a release tag alone is not a host feature test. | Before exposing a feature, check actual Incus `GetServer().APIExtensions` or `HasExtension` and test its required permissions. Report `UNSUPPORTED` when unavailable; don't make a fallback custom REST transport or silently force guest root to satisfy an unsupported UID. |
| G10 | **P2 — evidence discipline** | The recent Box test had an accepted creation receipt, conflicting partially populated Box state and intermittent gateway failures; daemon version **7.5.1** differs from reviewed SDK **7.6.0**. | No new Box creation or destructive cleanup against ambiguous prior task until exact native identity/state can be read. Do not count an HTTP/gateway or installed runtime preflight as SDK native verification. Record SDK tag, compiled Go version, daemon version/extensions and original native operation ID in subsequent trials. |

## Simplest actual execution order

1. **No Box mutations needed for the first proof:** a tiny in-memory MCP SDK test with two Bearer tokens. Assert `req.Extra.TokenInfo` accurately reflects the credential for each Tool call, including revoked and legacy-version requests. Verify runtime identity is never inherited from another request, even with one shared `mcp.Server`.
2. In **one verified disposable nested Incus project**, test project root disk/default profile, proxy and NIC ACL privileges under a non-admin `incus` user, foreign denial, safe instance identity, long-poll behavior, Exec return/output and SFTP exclusive file create.
3. Add a second **disposable nested instance** only if directional A→B Bridge peer tests are possible, test IP change/anti-spoof/IPv4/IPv6 and inner NAT. Stop if isolation cannot be proven. Clean only exact owned native objects, not the outer host.

**Decision discipline:** Do not add a homegrown auth/session layer, privileged helper, generic network manager, in-guest file patch service, or extra REST gateway on speculation. If strong file conditional replace/delete or native Bridge peer guarantees remain unmet, surface **the smallest specific contract choice** for the owner; do not silently water down P0 or force a workaround against upstream semantics.
