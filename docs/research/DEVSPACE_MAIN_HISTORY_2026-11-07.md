## Product and architectural scope (mandatory)

DevSpace is a **local MCP coding-agent/workspace execution layer**, not an Incus or container controller. It connects external MCP hosts to allowed local project directories and delegates bounded turns to coding providers; ChatGPT/Claude/etc. remain the orchestrators. The local subagent CLI does not require the remote MCP server or a tunnel; the MCP HTTP service requires operator-provided external connectivity if used remotely. Although the README says no hosted DevSpace service, its implementation **does run a local daemon for subagents**. Do not misread its marketing as “no local background process.”

**BoxWeave v1 imports only engineering invariants and testing methods that fit its existing 20 tools and local CLI:** Go + official Incus/MCP Go SDK, Incus-owned UUIDs, native container operations, bounded guest Exec/files, strict network policy, SQLite Operation/UNKNOWN, and independent nested installations. Never import DevSpace's multi-provider adapters, OAuth browser flow, Git worktree API, host Shell, generic JS workflow engine, UI, persisted coding sessions, provider daemon or tracing platform as new BoxWeave product features. External development/verification agents may use similar tools **outside the standard customer runtime**. See [permanent scope](../decisions/PRODUCT_BOUNDARY.md) and [Agent workflow](../development/AGENT_WORKFLOW.md).

### One causal sequence worth preserving in acceptance

DevSpace's Worktree cleanup sequence shows why **compensation cannot be assumed successful**:

1. Delete a native resource (Worktree); the durable state update fails.
2. Attempt compensation from the retained recovery reference; if successful, independently read back original state.
3. Inject a *second* failure during compensation. Record **original effect, persistence failure, compensation failure, and remaining identity**; do not classify as restored.
4. On restart, preserve exact ownership and block unsafe replay while evidence is ambiguous.

For v1 this becomes an **Incus + SQLite + owned forward/peer dependency failure-injection** test in the existing deletion/UNKNOWN flow, **not** a generic distributed transaction or Saga framework. No separate resource coordinator/service is authorized.

## Test-method translation — preserve evidence tiers

| Layer | Suitable use | What it **cannot** prove |
|---|---|---|
| **T** typed/unit/fake adapter | Inject lost reply, cancel race, SQLite errors, interrupted compensation, version mismatch and malicious identity/path values | Actual native Incus state, packet isolation, guest Exec or on-host file safety |
| **I** installed MCP/CLI black box | Install exact candidate, discover current MCP schemas, call all declared tools and CLI leaves, observe live transport and original Tracking/Operation IDs | Native network enforcement without an independent Incus/packet witness |
| **N** installed real Incus, including authorized nested layers | Actual Box UUID/config, guest Exec exit, native guest file effect, forward lifecycle and IPv4/IPv6 packet behavior | Independent verification by the same actor claiming it passed |
| **V** independent Verifier/post-read | Independently read native resources, original incidents and exact binary digest, check negative side effects and releases | Cannot be replaced with a mocked provider, a simulated browser or a model-produced PASS |

A recorded MCP/adapter exchange is useful to **reproduce** failures deterministically. It is not the same as a real ChatGPT client, a live Incus daemon, an external LAN probe, or an independently observed outcome. The QA harness must explicitly label a simulated host/provider/native layer and whether a negative control proved the test was able to fail. Run the independent verifier with minimal needed authority; a model prompt, Git worktree or client-side filter **does not** enforce read-only access. Do not add a new v1 role or per-Box RBAC to obtain this separation: use existing viewer access, separate disposable installations and operator-approved test credentials as appropriate.
