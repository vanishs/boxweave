Local labels change display metadata only. Native network membership and account identity are separate. Shared membership is supported only for new containers after exact native-network-tenant/v1/local capability, advertised create field and fresh enforcing Guard checks. Existing containers cannot be reassigned. Policy edits are destination ingress source lists, full revision CAS and the upstream atomic batch interface; unrelated policy fields are preserved. Unsupported, stale or degraded capability blocks grants. A degraded revoke remains pending until fresh enforcement observation.

Port profiles are server-trusted, preapproved protocol/port/target/audience presets. Plans and dispatch recheck exact target creation identity, IP, route conflicts and app ownership nonce. Unpublish removes only an app-recorded matching route. TCP and UDP are distinct resources. Passthrough provides neither source filtering nor TLS. Receipt success reports route configuration or Guard observation and explicitly keeps connectivity_tested=false; independent packet observations supply connectivity evidence.
