## Risk dispositions and handoff

1. **Fixed in source candidate:** browser fixture hardcoded port collision. Keep the ephemeral-port patch and verify real Chromium fixture checks in CI; this change does not require changing the installed runtime or stable release tag.
2. **Existing risk freshly reproduced:** upstream/provider create can return a 500 after a real Box exists. Inspect by original name/incarnation; do not blindly re-dispatch or delete an unknown result. The dedicated Box is retained as an evidence scene until a separately confirmed cleanup decision.
3. **Remain conditional:** R-02 unprovisioned on outer host; R-04 opt-in and not globally certified; nested workload not executed in this round; D4 positive allowlist, external OAuth/TLS/desktop, E2–E4, old-version migration/rollback and inference are U/BLOCKED. Historical reports remain version- and environment-scoped.
4. **Next smallest checks:** run protected/deprovisioned R-02 and R-04 on an isolated host with a known guest; perform specifically permitted nested create/hello/stop/delete and monitor original-name cleanup; test a real external OAuth client with an authorized private TLS endpoint; preserve create-after-commit trace metadata when reproducible.
5. **Resource boundary:** no mutation to original older Boxes; the isolated Box `bwaudit-0430-1103` was created despite an ambiguous response and is intentionally retained for independent investigation. Do not infer that source fixture PASSES prove a running production host upgrade.
