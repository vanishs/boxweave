## Explicit v1 contract choices, no feature creep

1. **Keep official SDKs**. Real v1 connection/Tool/runtime testing comes after implementation; there is **no SDK P0 reason to switch MCP Go libraries** or add REST/transport wrappers.
2. **`box_file_apply`:** keep the **one existing tool** and modes `create|replace|delete`, without adding a patcher or guest agent. SFTP exclusive create is a viable baseline with path/type and negative race validation. **`replace/delete` MUST return `UNSUPPORTED` whenever native atomic condition + same regular inode cannot be guaranteed**; hash comparison before a blind write/delete is not acceptable. This is a **known P0 contract capability limit**, not a hidden PASS; user-approved changes to this safety guarantee would be a separate product decision.
3. **`box_exec` / `operation_output_get`:** default to **native `RecordOutput:true` without non-nil stdout/stderr writers** for detached/recorded execution where appropriate, persist original op ID and native output log paths, read them with the official SDK native HTTP client, and page/cap/retain output under BoxWeave's existing SQLite operation journal. `RecordOutput:true` **with output writer** synchronously waits and may delete native logs before a durable receipt: do not combine these. An optional live-streaming worker is separate from the MCP request lifetime.
4. **`operation_cancel`:** queued-undispatched can be canceled with a journal transaction; a *running* Exec can be signaled only if BoxWeave still owns a live native control WebSocket and can **verify termination**. A plain Incus operation `Cancel()` returned unsupported on the tested detached Exec. If there is no live control connection or final observation, return **not confirmed/UNSUPPORTED or UNKNOWN as appropriate**, never promise that closing the HTTP request or a native operation cancels guest work.
5. **Native UNKNOWN:** reuse existing request's idempotency key and journal. A timed-out native create may have made a real Box; obtain original op ID when returned, otherwise reconcile exact Project, name and later UUID/incarnation. **Do not re-dispatch on timeout**. No Incus/Cowsql repair code belongs in v1.
6. **`box_peer_set`:** retain owner-selected installer-precreated single shared ACL, restricted TLS + Scriptlet, source/destination IPv4+IPv6 rules, native ETag, UUID/current NIC binding, native IPv4/IPv6 source anti-spoof. The actual **multi-NIC partial kernel-reload** result remains UNKNOWN; v1 must never report a new grant fully effective/safe from a mere database update success. Fail closed or stop admitting peer grants when full native/network verification is missing.
7. **MCP HTTP configuration:** use SDK **Stateless Streamable HTTP**, `RequireBearerToken`, `req.Extra.TokenInfo`, explicit `CrossOriginProtection`, bounded body, and **`PropagateRequestCancellation:false`** for admitted durable mutations. Keep MCP request context for admission/authentication; use a separately owned durable worker context after persistence. A working SDK in-memory test does not substitute for real v1 SQLite/process restart acceptance.

## What remains after SDK research (development/release, not more upstream research)

- **No v1 Go controller or installer exists yet**: real 20-tool black-box, SQLite journal/recovery/restart, actual ChatGPT connection, shared-host global Scriptlet migration, token scope across real external proxy, and binary-specific acceptance remain untested.
- **File atomic conditional replace/delete** is not natively provided: keep unsupported rather than implementing unsafe behavior.
- **Live Exec cancellation** depends on a preserved native control channel; robust cross-worker/crash/restart cancellation cannot be claimed from this SDK test.
- **IP ownership changes/reuse, IPv6 filtering, established-flow cutoff and shared ACL partial NIC failure** remain separate security acceptance. Avoid claiming full P0 release readiness.
- Nested Cowsql failure is an **environment reliability record**. Debug the Box/Incus environment independently if useful, but **do not expand BoxWeave v1 product scope or create a Cowsql patch component**.
