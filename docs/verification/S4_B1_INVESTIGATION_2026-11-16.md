B2 must not globally enable egress for unowned/direct-native instances. Existing prepare refuses an already occupied ACL name; safe B2 installer reuse requires exact independent ownership/shape/foreign-reference proof, not blind adoption.
- Upstream tagged `client/incus_network_acls.go` supports `GetNetworkACL` with ETag and `UpdateNetworkACL(...,ETag)`; `shared/api/network_acl.go` provides complete ingress/egress/UsedBy. Tagged `internal/server/network/acl/acl_bridge.go` iterates affected NICs and calls `ReloadDevice` per running NIC, returning at the first error: kernel-rule fanout is **not atomic**. Tagged `internal/server/auth/router.go` routes the whole restricted-TLS client class to Scriptlet when configured; native TLS restricted-project access contains permissions and exceptions that cannot be reproduced by a generic allow fallback.

| --- | --- | --- |

| IP change/DHCP lease reuse and UUID→NIC address lifetime | **UNVERIFIED** | Must prove stable exclusive lease/reservation or remove grant before reuse; snapshot-only polling is insufficient |

| Forward/peer/Delete racing, crash, unknown native effect | Existing S4-A lifecycle/UNKNOWN code reviewed; network compositions **UNVERIFIED** | Ordered durable multi-resource locks and per-step original readbacks; test in B3/B5 |
