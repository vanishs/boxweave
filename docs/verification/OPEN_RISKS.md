## Final pre-development P0 SDK contract closure (2026-11-08)

**Authoritative recent status:** [test plan](P0_SDK_LAST_GATE_PLAN_2026-11-08.md) and [native/real-HTTP results](P0_SDK_LAST_GATE_RESULTS_2026-11-08.md). **MCP official Go SDK**: actual 2026-07-28 discover + 2025-11-25 initialize, typed Tools/error, 20 concurrent admin/viewer identities, Token expiration/revocation, HTTP Origin/Host/body cap and detached admitted handler after HTTP cancellation all **PASS** in an isolated loopback SDK harness. **Incus official Go SDK**: explicit native async Exec receipts, recorded stdout/stderr retrieval from a fresh client, control-WebSocket signal termination, exclusive SFTP create and one-NIC IPv4 source-IP filtering all **PASS** in tested configurations. Original native Cowsql lost-leader + timed-out-but-created instance is **UNKNOWN/environment-only**, not a v1 patch request. Last test cleanup was **`P0_FINAL_CLEAN_EXIT=0`** with no L2 instances or test Project.

**Important known limitations, not concealed as PASS:** native `CreateInstanceFile/DeleteInstanceFile` don't implement atomic hash-based conditionals; `box_file_apply(replace|delete)` must report `UNSUPPORTED` until a real atomic guard can be proven. Detached native Exec `Operation.Cancel()` cannot cancel the running process; a live control-WebSocket can signal, but no guarantee survives lost socket. Bridge ACL reload per NIC is not atomic; IPv6 anti-spoof, IP changes and actual multi-NIC reload failure remain **release/implementation acceptance**. The 20-tool v1 binary, SQLite journal and actual ChatGPT integration remain **UNTESTED**. This completes **predevelopment SDK capability investigation**, **not** P0 product release approval.

## 2026-11-08 real nested native validation — replace first blocker status

Read [actual native B/C result report](SDK_NATIVE_BATCH_RESULTS_2026-11-08.md). **Narrow demonstrated PASS**: L1 Cowsql database recovered by guest-local stop/backup/start; original timed-out native create actually produced an owned STOPPED child and was *not* retried; two child lifecycle/stop/delete and storage readback, official SDK asynchronous Exec (including observed exit 7), native guest file read/write/delete and one exclusive-create refusal, Bridge NIC IPv4+IPv6 default deny / admin-granted A→B / revoke, TCP/UDP packets, and both TCP+UDP **loopback** `proxy` after explicit project permission. These are nested raw Incus/SDK observations, **not** v1 controller acceptance.

**Confirmed P0 blocker on O-003/O-004:** In the tested native `incus`-only restricted Project `user-1003`, runtime credential could attach an administrator-prepared ACL to its own NIC but **could not create or update ACL rules** in the inherited `default` Project. A second fresh confined Project failed when admin attempted `features.networks=true`: **OVN required**. The small BoxWeave `box_peer_set` implementation cannot claim native restricted-runtime semantics by relying on admin-only ACL edits. Subsequent [native TLS/Scriptlet tests](INCUS_ACL_AUTHZ_TLS_SCRIPTLET_2026-11-08.md) **completed that investigation**: project-scoped TLS returned HTTP 403 for inherited ACL; default-scoped TLS was too broad; native Scriptlet precisely authorized existing ACL edits but not object-named ACL creation. Remaining choice concerns daemon-global routing and dynamic ACL creation, not whether the official SDK can edit ACLs. No automatic custom host firewall, extra API, or privilege escalation is authorized by this research.

**Confirmed P0 configuration prerequisite on O-005:** default `restricted.devices.proxy` blocked native proxy; a local administrator set `restricted.devices.proxy=allow` **only on the test Project**, after which the restricted runtime user added native TCP/UDP proxy devices and loopback packets succeeded. The test grant was later unset after device removal. External binding and instance IP-change cases are still native UNKNOWN. The original transient Cowsql failure is **not** proof of a persistent Incus bug; the root cause was not isolated.

## Final 2026-11-08 three-Box experiment — supersedes the earlier design blocker

The [real shared ACL acceptance, legacy TLS matrix and final cleanup](SINGLE_SHARED_ACL_SCRIPTLET_ACCEPTANCE_2026-11-08.md) establish a **selected native design**: **one installer-precreated BoxWeave-exclusive shared ACL**, each managed NIC configured default ingress reject/egress allow **before start**, and **only** native Scriptlet-authorized restricted TLS **GET/PUT** of that ACL through the official SDK with ETag. The owner accepted global `authorization.client.tls-restricted=scriptlet` with a prominent README risk notice. **Do not implement per-Box runtime ACL creation, native Incus administrator service or custom privilege helper** merely to work around the initial Project creation check.

Three owned child NICs shared the ACL; source+destination IPv4/IPv6 A→B access worked, B→A/C→B denied, SDK revoke restored deny, native proxy TCP HTTP 200 and UDP echo survived revoke, and an independent simulated existing restricted TLS client had **identical** allow/deny/Exec results before/after routing. The peer-credential negative tests all returned **403** for other ACLs/create/delete/instance/Project. Native test resources and global route/scriptlet/certs were restored/removed (`FINAL_CLEAN_EXIT=0`).

**P0 product design choice is resolved; P0 installed-controller acceptance is NOT complete.** Actual shared-host policy migration/rollback, anti-spoof/current IP changes, long-lived sessions after revoke, per-NIC partial update failure, public LAN tests and v1 implementation remain OPEN. The twice-observed nested Incus Cowsql leader failure is separate OPEN reliability evidence; failed create receipts can coexist with real created native resources.

## Verified native TLS, Scriptlet and ETag boundaries (2026-11-08)

[Follow-up tagged-source review and real official Go SDK tests](INCUS_ACL_AUTHZ_TLS_SCRIPTLET_2026-11-08.md) supersede the earlier untested TLS suggestion. A restricted cert for the business Project cannot edit inherited `default` ACLs (HTTP **403**); one restricted to `default` can edit ACLs but reads unrelated default-Project resources. Incus **native Authorization Scriptlet** allowed exactly `network_acl:default/bwv1-acl-1108-a#can_edit` while denying another ACL's read/edit/delete (**403**). Go SDK `UpdateNetworkACL(...,ETag)` rejected a stale ETag with **412** and left the updated ACL intact.

**Historical per-Box ACL creation blocker (subsequently avoided by selected one-ACL design)**: `POST /1.0/network-acls` authorizes `project:default#can_create_network_acls` before parsing the body-provided ACL name. A test scriptlet grant proved an arbitrary-name ACL could be created even when later object access was denied. Moreover `authorization.client.tls-restricted=scriptlet` routes **all** restricted TLS certs to one global policy and replaces automatic TLS certificate Project restrictions. This is an upstream implementation boundary, **not** a reason to grant broad native admin rights or invent a generalized ACL manager. Resolve narrow creation and safe shared-daemon policy before implementation; object-limited edits alone are not a full `box_peer_set` acceptance.

The isolated nested test fully cleaned up: test TLS trust entries/keys, Scriptlet and routing, loopback HTTPS listener, ACLs and Project; two stale **previous test-only** restricted certificates with no Projects were also revoked. Final native inventory showed only the original `default` Project/bridge and no test ACLs or instances. Real L0/shared-daemon policy remains **UNTESTED**.

## New official SDK capability checks

The [2026-11-07 Incus/MCP SDK review](../research/OFFICIAL_SDK_FIT_2026-11-07.md) confirmed limitations that cannot be resolved by simply writing more BoxWeave code:

- **S01 P0:** Incus `Operation.WaitContext` may invoke native cancel when its context expires. Use `GetOperationWait`/`GetOperation` for observational waits and explicitly test non-cancelation.
- **S02 P0 corrected:** root/`incus-admin` has full local Incus authority; a non-root `incus`-only user has native per-user Project confinement. `UseProject` is not a credential. Test denied foreign/admin calls, project `restricted.*` allowances for proxy and nesting, and NIC ACL behavior; try restricted TLS before any helper.
- **S03 P0:** Instance methods are often name-addressed. Resolve stored `volatile.uuid` to live owned project/name and recheck UUID before effects.
- **S04 P0:** Incus guest file API has no atomic hash/ETag conditional write/delete. Strong `box_file_apply` modes are blocked until a safe native-compatible implementation is proven; return UNSUPPORTED instead of claiming atomicity.
- **S05/S06 P0:** Prefer instance proxy-device host listener and one tested NIC ACL topology; same-bridge packet enforcement needs proof.
- **S09/S10/S11 P1:** MCP SDK v1.8 handles modern Stateless HTTP and typed tools; explicit external HTTP auth/Origin protections and real ChatGPT/legacy compatibility tests are still necessary.

These are **SDK contract alignment** checks, not defects attributed to the official upstreams. No v1 real-environment acceptance has been run by this document change.

## Source-level follow-up: implement by SDK semantics

[Second-pass native source research](../research/SDK_GAP_CLOSURE_2026-11-07.md) tightens the already-listed validation risks, without opening a general platform backlog:

- **P0 / O-009:** In typed MCP Tool handlers, authenticate **`req.Extra.TokenInfo`** on every call. `auth.TokenInfoFromContext` is only the HTTP middleware accessor; prove no actor/role cross-request leakage, revocation and legacy client handling.
- **P0 / O-003:** Bridge NIC ACL group selectors are unavailable; require trustworthy current IP/IPv6 binding and native anti-spoof, fail-closed on address change. No custom ACL editor.
- **P0 / O-010:** Native file upload defaults to `O_CREATE|O_TRUNC`, not exclusive create; SFTP `O_EXCL` is **only a native test candidate**. Strong conditional replace/delete still require real atomic proof or an explicit owner product choice.
- **P0 / O-011/O-012:** `ExecInstance(RecordOutput=true)` with output writers can synchronously wait before returning; native recorded-output getters are private. Use a tested SDK-streaming mode with durable worker output. `GetOperationWait` modifies shared HTTP Transport `ResponseHeaderTimeout`; prefer bounded `GetOperation` polling until concurrent semantics are tested.
- **P1 / O-004/O-013:** Confined Project must have its `features.*`, root disk/Profile and required managed NIC/network/ACL rights configured **before the first instance**; feature choices can lock afterward.
- **P1 / O-007:** Parent NIC anti-spoof controls can block nested L2 forwarding with new MAC. Prove nested managed-bridge NAT instead of disabling native protection broadly.

These are tagged SDK facts plus honest native UNKNOWNs; no live acceptance was run in this document change.

## Release rule

An unsupported or unverified native behavior may be a real BLOCKED/UNSUPPORTED result, not a fabricated PASS. Failure in mandatory core functions (including private network deny, native forwarding and file read/write) prevents claiming full P0 acceptance. Keep independent test evidence, actual upstream versions and intact original UNKNOWN/failed resources.
