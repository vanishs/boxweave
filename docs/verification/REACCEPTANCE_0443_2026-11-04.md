## Decisions, open defects and handoff

1. **FIXED in released v0.44.3:** the first-install MCP path bug, with a real fresh and failed-install recovery proof. A successful 0.44.3 Release/CI is not equivalent to default stable-pin promotion.
2. **OPEN upstream write ambiguity:** exact authenticated nested MCP create returned error although the Box was running. Follow the original incarnation/receipt; do not retry a mutator based only on the exception. Independent original stop/delete and cleanup were confirmed.
3. **OPEN disk contract discrepancy:** the outer v0.128.0 Provider accepted a 10GB to 8GB disk resize. Treat the returned value as observed metadata only; check real disk semantics upstream before promising shrink refusal or data safety.
4. **BLOCKED/UNVERIFIED:** no OTel collector, R-02 task store not provisioned, no proven full R-04 guard, D4 allowlisted positive, real external clients/TLS, production external-Provider upgrade/rollback, full old/future API compatibility and E2–E4.
5. Task-owned `bwaudit-1104-combo-container` and `bwaudit-inner44-container` were independently confirmed deleted. The clean installed `bwaudit-1104-clean44-container` and recovery `bwaudit-1104-release-container` are handoff test installations; preserve their explicit identities if retaining, and record deletion separately if cleaned. Do not delete or overwrite historical operator failure evidence.

**Next operator gate:** on a separately authorized target, explicitly install `--version 0.44.3`; run `boxweave doctor --mcp`, check actual running daemon and MCP versions, and only then exercise the external managed-Provider protected-unit upgrade/rollback. Keep v0.43.1 as default until a separate stable-promotion decision.
