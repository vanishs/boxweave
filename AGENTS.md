# BoxWeave v1 — mandatory rules for coding Agents

Read [permanent product boundary](docs/decisions/PRODUCT_BOUNDARY.md), [scope](docs/product/SCOPE.md), [MCP catalog](docs/design/MCP_TOOLS.md) and [security](docs/design/SECURITY.md). v0.x and Containarium are references, not implementation mandates.

**Upstream SDK-first rule:** treat official Incus and MCP Go SDKs as trusted foundations. Use their native APIs and actual semantics rather than inventing a second engine, MCP transport or impossible guarantees. Before coding privilege separation, native wait/cancel, conditional guest files, TCP/UDP forwarding or same-bridge ACLs, read [SDK capability/architecture fit review](docs/research/OFFICIAL_SDK_FIT_2026-11-07.md).

**Second-pass mandatory source findings:** Read [native SDK gap closure](docs/research/SDK_GAP_CLOSURE_2026-11-07.md). MCP typed Tool auth uses **`req.Extra.TokenInfo`**, not HTTP `auth.TokenInfoFromContext`; Incus ordinary file upload is not exclusive create; Bridge ACLs have no group selectors; `RecordOutput`+writers can block the initial async Exec; read-only wait needs safe SDK use; native Project root disk/features must be prepared before first Box. Never substitute a new private protocol/helper/agent for the appropriate upstream API.

**Actual SDK acceptance update:** Read [2026-11-08 tested native Incus 7.6 B/C results](docs/verification/SDK_NATIVE_BATCH_RESULTS_2026-11-08.md). The ordinary restricted `incus` runtime could attach a native Bridge NIC ACL but **not create/update its default-Project rules**; in the tested non-OVN daemon `features.networks=true` required OVN. Native TCP/UDP instance proxy **did** work after host-local Project `restricted.devices.proxy=allow`. Never claim an admin-edited ACL is a restricted-runtime `box_peer_set` PASS, run the public MCP process as native admin to bypass the gap, or re-dispatch an ambiguous create.

**New mandatory real ACL authorization evidence:** Read [native Incus 7.6 TLS/Scriptlet/ETag probe](docs/verification/INCUS_ACL_AUTHZ_TLS_SCRIPTLET_2026-11-08.md). Ordinary restricted TLS is Project-scoped, not ACL-scoped. Built-in Incus Scriptlet **proved exact existing ACL edit** with denied foreign ACL and native stale-ETag **412**, but `can_create_network_acls` is checked on the **Project before decoding the ACL name**. Never claim that Scriptlet alone prevents unauthorized ACL creation. Changing daemon-global `authorization.client.tls-restricted=scriptlet` also disables automatic TLS Project restrictions for every client on that route; do not apply the test scriptlet to a shared Incus daemon or add a privileged helper without resolving this explicit owner decision. Final test cleanup was independently PASS.

**Upstream-first supplement:** Read [20/20 SDK-native tool mapping](docs/research/SDK_TOOLS_NATIVE_MAPPING_2026-11-07.md). Non-root `incus`-only users have native Project confinement (unlike root/`incus-admin`); prefer native MCP `auth.RequireBearerToken`, Incus `api.StatusErrorMatch` and SDK Host/body guards over homemade frameworks. These are source findings, not native PASS evidence.

1. **English artifacts; requester-language discussion.** Repository source, docs, CLI/MCP contracts, tests and release artifacts are English. Reply to the requester in their chosen/current language.
2. **Evidence not aspiration.** A design/CI pass is not a real native Incus or installed-Box acceptance; report PASS/FAIL/PARTIAL/UNKNOWN accurately with original Tracking IDs, actual native Box/forward state and the independent witness for LAN claims. For bug-fix versions, formal CI auto-Release is permitted only after exact-candidate independent nested/native regression verification.
3. **Keep permanent scope narrow.** Single-host Go controller with official MCP/Incus SDKs, no Containarium, Caddy, public REST/Web API, generic ACL/RBAC, guest Agent, host shell, website management or other excluded features. Never silently convert exclusions to P1.
4. **Owned native resources only.** Confirm native Box UUID/incarnation, local ownership and permissions before each sensitive read or effect; deny foreign Incus/host files, raw config, arbitrary destinations and host-root command execution.
5. **Agentless development loop first.** Create Box/verify readiness; list/read/conditionally create/replace/delete one guest file; async guest-root Exec, original output/reconnect/retest. Guest Git/Exec handles complex source patching; no custom patch engine.
6. **Native networking only.** Default private deny with actual IPv4/enabled IPv6 proof; one `box_peer_set` allow/revoke for an exact directional owned peer pair. Retain native Incus TCP/UDP forwards to owned Box ports and explicit public bind authorization. No Caddy or custom proxy/ACL editor.
7. **Admin/viewer credentials.** Revoke independently. Viewer may inspect sensitive guest data but cannot mutate or Exec; admin only manages owned resources. Never add per-Box Token delegation or role matrix without a new owner product decision.
8. **Async, context, and idempotency.** All mutations require reusable caller idempotency key and durable receipt, Tracking ID and distinct BoxWeave/native Operation IDs. Pass safe typed Go context through MCP/services/workers/native adapters; persist only safe context projection. Timeout/disconnect is not proof of native stop; UNKNOWN is not silently replayed.
9. **No fictitious cancellation, deletion atomicity or file atomicity.** Box deletion must resolve owned forward/peer dependencies under identity locks and retain partial/UNKNOWN records. For failed delete, existing Operation/Box/forward tools provide sanitized evidence; private host logs are a separately authorized local operator action. Guest services should be managed inside the guest, not by extending BoxWeave into a process supervisor. Prove queued no-dispatch and native running-Exec termination. Do not call pre-read SHA + write atomic without point-of-use evidence. For unsafe file changes, fail closed.
10. **Nested compatibility not management.** An inner BoxWeave independently installs and operates the same feature contract without sharing parent sockets, tokens or database; parent sees an ordinary owned Box.
11. **Dependency versions and shared-host safety.** Explicit local install/upgrade checks and reconciles required/observed Incus versions and ownership. Shared Incus disruptions need separate local impact approval; never auto-adopt foreign instances or reboot entire host.
12. **Real negative black-box tests.** Cover all installed MCP/CLI leaves, forged/stale UUIDs, unsafe path, Token auth, port/peer cross-owner attacks, crash/UNKNOWN and native state absence of effects. Test L0/L1/L2 where supported.
13. **Separate independent review when practical.** Finder captures actual failure; Fixer changes narrowly; Verifier runs original reproduction against exact installed bytes in another approved test environment. Keep test orchestration out of customer runtime.
14. **Safe release and collaboration.** No force push or unrelated cleanup; honor existing concurrent work and ownership. `v1` green CI can auto-publish a *real* new-version release, not docs-only assets or a host deployment. Preserve SHA, dependency versions and concise handoff.
