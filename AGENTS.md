A hard-to-fix subcase or indispensable owner decision becomes a **documented BLOCKED/UNKNOWN/DECISION_REQUIRED** with original IDs; continue **unrelated safe work**, never mark dependent safety or release PASS. ## Required source / commit / PR gates

**Before editing, committing or merging** read [CONTRIBUTING.md](CONTRIBUTING.md) and the [project quality and merge gates](docs/process/QUALITY_GATES.md). All Go source must pass gofmt, `go vet`, `go mod verify`, `go mod tidy -diff`, full race tests and compiled checks; all tracked text must pass UTF-8/LF/JSON/whitespace format tests. Install the repository-local hooks using `make hooks`; the pre-commit hook checks **staged content**, not only the worktree. Run `make verify`. PRs targeting v1 must pass the independent `quality-gate` job on the exact head SHA plus any stage-specific installed/native gates. **Failing format forbids merge; bypassing a local hook does not create an exception.** GitHub **now enforces** Ruleset #26842628 (`active`, exact `v1`, required `quality-gate`, strict freshness, no bypass); failing non-Draft [PR #118](https://github.com/vanishs/boxweave/pull/118) was blocked. Legacy `Basic protection` #26251692 remains disabled. Server merge protection is not a substitute for S1 phase-exit/native independent acceptance. No S1-to-S2 promotion, merge or release while a mandatory acceptance gate is still PARTIAL/UNKNOWN.

## Permanent product and trust limits

1. **Only 20 public MCP tools**, as listed in [MCP_TOOLS](docs/design/MCP_TOOLS.md), with the safe contracts in [MCP_TOOL_CONTRACTS](docs/design/MCP_TOOL_CONTRACTS.md). Permanent [scope](docs/decisions/PRODUCT_BOUNDARY.md) overrides earlier v0.x/research experiments. **No Containarium, Caddy, general ACL editor, public REST/Web control API, general host shell/files, custom firewall/forwarding daemon, guest Agent, snapshots, tracing platform, hierarchical RBAC, generic patch engine or extra recovery service**. No excluded feature is silently reassigned to P1.
2. Use **official MCP Go SDK + official Incus Go SDK**, typed Go API/contracts and stable upstream status semantics; do not build a second MCP transport, custom Incus REST SDK, wrapper server or local native DB patch. [20/20 SDK method mapping](docs/research/SDK_TOOLS_NATIVE_MAPPING_2026-11-07.md) and [last P0 real tests](docs/verification/P0_SDK_LAST_GATE_RESULTS_2026-11-08.md) are loaded by the relevant phase, not at every conversation.
3. Admin/viewer are the only MCP token roles; multiple independently revocable tokens. A typed Tool handler uses **req.Extra.TokenInfo** for the current caller. Viewer can inspect sensitive owned guest data but **cannot** mutate or guest-Exec. Neither role can manage foreign Incus resources. Control MCP loopback-only by default; operator-managed external proxy/Tunnel is not installed by BoxWeave.
4. Every native effect requires local owned Box **UUID/incarnation** and Project confirmation, actual restricted non-root OS service account, current capability check and independent postcondition. Name, IP and SDK UseProject alone **are not proof of identity or privilege**. No Incus-admin power for public MCP, parent/foreign Incus credential or arbitrary device/config privilege.
5. Every MCP mutation requires original caller reusable idempotency key, durable SQLite admission, Tracking ID and distinct BoxWeave/native Operation IDs, typed safe Go contexts, exact original intent and recovery evidence. **Never repeat a possibly dispatched UNKNOWN effect** merely because the request timed out. A canceled HTTP read wait or revoked token cannot undo proved-dispatched work. [Operations](docs/design/OPERATIONS.md) and [local manual UNKNOWN recovery](docs/process/UNKNOWN_MANUAL_RECOVERY.md).
6. Box Exec is **inside the owned guest** (guest UID 0 by default), never host shell. SDK **RecordOutput=true without output writers** can return original async operation and recorded stdout/stderr retrievable from a new connection. Detached **Operation.Cancel() did not cancel**; an owned live control WebSocket can signal and verify process termination. Don't fabricate kill, exit 0, output coverage, or reliable cancellation after losing the control connection.
7. Guest files: SFTP **O_EXCL** exclusive create passed one native test, but atomic hash-based conditional **replace/delete is not supported by the proved native API**. For box_file_apply(replace|delete), return **UNSUPPORTED** unless same-file atomic safeguards are genuinely proven; never fake CAS with hash-then-overwrite/delete or staging rename. Guest Git/Exec is the intended Agent code-edit path; no file patch engine.
8. Network: **one installer-precreated BoxWeave-exclusive Bridge NIC ACL** shared by only owned NICs, native ingress private deny, verified IPv4/enabled IPv6 anti-spoof and exact directional all-port box_peer_set; native **instance-owned TCP/UDP proxy devices**, not HTTP route/Caddy/general network-forward service. Owner **accepted daemon-global authorization.client.tls-restricted=scriptlet** with an explicit [README warning](README.md); installer must preserve existing TLS client permissions, protect dedicated exact-ACL GET/PUT key and prove rollback, never silently overwrite old authorization policy. [Network](docs/design/NETWORK.md), [real three-Box native proof](docs/verification/SINGLE_SHARED_ACL_SCRIPTLET_ACCEPTANCE_2026-11-08.md). Per-NIC reload failure, IP reuse and external LAN still need actual installed v1 acceptance.
9. Full install/status/upgrade only under **explicit local authority**, with actual dependency versions/sha/SQLite migrations and separate approval for shared Incus upgrade. No automatic whole-host reboot, unsolicited stable-L0 changes, foreign-resource adoption, production experiment or force-push. Nested controller installs independently with its own credentials/socket; no parent orchestra.
10. **Cowsql owner decision:** repeated missing leader in nested test Incus may be environmental; preserve the original incident and UNKNOWN native identity, but **do NOT develop an Incus/Cowsql database patch, storage repair service or extra v1 subsystem**. [Test report](docs/verification/P0_SDK_LAST_GATE_RESULTS_2026-11-08.md).

## Coding, documentation, acceptance and release

- Source, repository docs, MCP contracts, test names and release artifacts use English. Discuss results with the requester in their chosen language. Log important operations, decisions, failures, attempted fixes, actual test versions/digests and original native identities, **without secrets** in [EXECUTION_LOG](docs/development/EXECUTION_LOG.md).
- The phase card lists the small relevant [ACCEPTANCE](docs/verification/ACCEPTANCE.md) IDs; **unit, fake-native, CI source and upstream SDK-only PASS are not installed v1/native PASS**. Test positive and refused effects across the **actual installed** MCP/CLI surface, UUID spoof/foreign operations, failure/rollback, nested L1/L2 and independent physical LAN as required.
- Finder reproduces original failure, Fixer makes a narrowly scoped change, independent Verifier rechecks **the same source/binary hash in a separate authorized test** when feasible. If not independent, label it accurately. Existing [AGENT_WORKFLOW](docs/development/AGENT_WORKFLOW.md) defines evidence/calibration and local authority.
- An unfinished subcase or owner decision does not block all safe development, **but** missing mandatory release evidence does block publication. Only publish immutable exact accepted bytes after source hash, binary hash, CI and independent real/nested verification. A docs-only branch, green unit tests or root VERSION=1.0.0 are **not** a release.

**Do not load all historical research for routine work.** If a specific old regression appears, use [INDEX](docs/INDEX.md) to find the corresponding source/history/SDK and record why it was read. The [five-phase plan](docs/process/IMPLEMENTATION_PLAN.md) owns development ordering; keep docs and code consistent at all times.
