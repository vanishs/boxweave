# claude-code adapter

Claude Code registers MCP with the official user-scope CLI and writes a dedicated user rule. See [client setup](../../docs/CLIENTS.md) for profiles, prerequisites and validation limits.

GLM is supported through the same adapter with `--claude-provider zai` or
`--claude-provider zhipu`. See [GLM setup](../../docs/CLIENTS.md#glm-through-claude-code-030)
for client-side keys, optional model selection and verification limits.
