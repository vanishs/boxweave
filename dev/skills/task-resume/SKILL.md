# Task resume

- Confirm the original target, branch, dirty work, IDs, acceptance and observed state. Resume only the explicitly requested scope.
- Reconcile original native Operation receipts before dependent work. Never replay an uncertain effect or infer completion from lost contact.
- Use an existing checkpoint if useful; no new checkpoint is required for ordinary completed tasks. Report the next safe action and stop when complete or blocked.

## Early checkpoint before call-budget pressure (candidate)
For material interrupted work, preserve the minimum durable evidence, exact IDs and remaining checks.

## Phase-wide continuation (candidate)
Continue only independent actions in the authorized task; old phase cards and queued candidates are not authority.

## Finish Gate (candidate)
Use optional tool checks if the selected workflow requires them. A recorded gate cannot override actual product acceptance.
