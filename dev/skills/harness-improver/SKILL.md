# Harness improver

## Owner-invoked improvement cycle (candidate)
Only start when the user explicitly requests harness improvement. Select one evidenced problem, compare against the current implementation, make the smallest justified change, run a relevant check and report the outcome. A proposal or prior rejection does not authorize another attempt. Stop at the requested scope, a failed budget or missing evidence; no recursive improvement or automatic promotion.
