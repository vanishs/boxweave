# Continuous learning

Ordinary tasks end with the requested result and necessary verification. Do not create a learning record or reopen a candidate merely because a task ended or a check failed.

If a reusable issue is relevant to an explicitly requested improvement, record the observed evidence, affected asset, concrete benefit and a bounded test. Leave unproven proposals as candidates. No automatic execution or self-assigned follow-up.
